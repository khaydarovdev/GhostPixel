Reveal a message

GhostPixel reads the plain "GPX1" header first, then decrypts with your password. A checksum tells a right password from a wrong one. Three tries, like the console app.

Detect hidden data

No password needed. The scan checks for our signature, then runs two statistical tests (RS analysis and the chi-square attack) on growing bands from the top. A band only counts when both tests agree.

Break the cipher

Our README says it plainly: the cipher is for learning, not for real secrets. Here are two ways to break it, run on GhostPixel's own cipher code.

Puzzle 1: two ghosts, one password

The key stream depends only on the password, so two messages hidden with the same password share it. Guess ghost A's message and ghost B decodes itself, letter by letter, with no password at all.

Honest scope

  • The cipher is for learningXOR with a password-seeded stream. Fine for a class project, breakable by anyone with the code and a few samples, as Break the cipher shows.
  • Detection is a score, not proofNoisy photos can push a clean image up. A very short message from another tool can stay under the radar.
  • Our own messages are easy to spotOn purpose: the plain GPX1 header lets Reveal tell "no message" from "wrong password".
  • Editing kills the messageJPEG, resizing, cropping or recolouring destroys it. Only lossless copies keep it.
